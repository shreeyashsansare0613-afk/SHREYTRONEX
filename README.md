# SHREYTRONEX

Personal Intelligence System — prototype 0.1.

This version includes a responsive blue futuristic interface, local chat demo, planned voice/device/settings panels, a PWA manifest and a service worker.

Important: this is only a front-end prototype. It is not connected to an AI model, account system, cloud sync, microphone, calls, SMS, WhatsApp, or laptop controls. Do not enter private information.

## Publish with GitHub Pages
1. Open repository Settings → Pages.
2. Under Build and deployment, choose Deploy from a branch.
3. Choose branch `main` and folder `/(root)`, then Save.
4. Wait for deployment to finish.

Never commit passwords, API keys, phone numbers, or other private information.
